> 立项：2026-11-12 ｜ 状态：实施中 ｜ 进度权威：`PLAN.md`
> 相关：`references/continuity-rules.md`（C10 v2）、`references/stage-card.md` 第 6 节、
> `references/stage-script.md`、`scripts/validate.py`、`scripts/prompt.py`、`bible/scenes.yaml`

## 1. 为什么要做（调研结论）

现有 `scene_description` 是一段给人读的散文，四要素标签（时间/地点/物件/风格）
**缺了图形生成提示词最关键的维度**：景别、机位、运镜、光源软硬方向、色调；
且散文是非结构化文本，机器无法拼装成 prompt，同一场景跨集无法保证光线/色调不漂移。

2026-11-12 调研了各家官方指南与实战总结（阿里万相文生图/文生视频 Prompt 指南、
可灵官方提示词公式、Seedance 2.0 指南、Sora/Veo 实战帖、竖屏短剧制作规范），
优秀实践收敛为以下原则：

1. **公式高度收敛**：
   - 文生视频 = 主体 + 动作 + 场景 + 景别 + 角度/运镜 + 光线色彩 + 风格 + 声音 + 约束
   - 文生图 = 主体 + 场景 + 镜头语言（景别/视角）+ 氛围 + 细节修饰 + 风格
2. **可观察 > 主观形容**：写「蓝调时刻、右侧暖光、低对比」，不写「氛围感/高级感」——
   模糊词等于没描述，必须进黑名单。
3. **先定镜头再写画面**：景别/机位放最前给模型取景依据；一条只写一个主景别、一种主运镜。
4. **光线是必填维度**：光源方向 + 软硬（柔/硬）决定情绪，缺光线的场景描述不合格。
5. **一致性靠锚点复用**：同一场景所有集复用完全相同的「空间基因 + 光线基调 + 色板」，
   每场只写本场差异（时段、特殊布置）——这就是防跨集画面漂移的机制。
6. **正面表达**：写「稳定运镜」不写「不要晃动」，否定词会被模型当指令；
   `must_not_happen` 是创作边界，**永远不进提示词**。
7. **竖屏短剧特性**：9:16、面部特写占比高、双人前后站位正反打、靠纵深不用横宽。
8. **一镜一主体一动作**：提示词按镜头拆分（W5.2b 分镜表 shots.yaml 的领域），
   场景层先保证「这一场长什么样」是结构化的。

## 2. 构建思路（四层）

```
bible/scenes.yaml（场景锚点库 · 跨集复用，视觉基因）
   ↓  scene_ref 引用 + 本场差异
场景卡结构化视觉字段（每场：景别/机位/光线/色调 + 散文 scene_description）
   ↓  压缩
剧本【场景】行 v2（8 标签：时间/地点/景别/机位/光线/色调/物件/风格 + ≥30 字描述段）
   ↓  拼装
scripts/prompt.py 导出器（锚点 + 卡片字段 + 人物形象四件套 + 道具 → 生图/生视频提示词）
```

### 2.1 场景锚点库 `bible/scenes.yaml`

每个常市场景定义一次，全剧复用：

```yaml
scenes:
  - id: fish-stall
    name: 老周鱼摊（B7）
    aliases: [老周鱼摊前, 老周鱼摊后, 幸福里菜市场 · 老周鱼摊, 幸福里菜市场入口, ...]
    space: 白炽灯一排 +案板 + 水氧机水箱 + 泡沫箱 + 单宽通道（可拍的空间基因）
    lighting_anchor: 白炽灯顶光偏硬，暖黄；时段可变但光源固定
    palette_core: [水泥灰, 白炽灯暖黄, 泡沫箱白]
    ambience: 水氧机嗡嗡、叫卖、赊账小本本
    vertical: 竖屏前后站位：案板前景、通道纵深、人物胸像为主
```

- `aliases`：卡片 `location` 写法五花八门，靠别名归一到同一锚点。
- `palette_core`：该场景**固定色**，本场 `palette` 必须包含全部核心色（QC 校验，防漂移）。
- `lighting_anchor`：光源是固定语义（灯管/日光/霓虹），本场 `lighting` 只写时段与软硬差异。

### 2.2 场景卡结构化字段（C10 v2 必填）

| 字段 | 要求 | 例 |
|------|------|-----|
| `scene_ref` | 锚点 id，必须存在于 scenes.yaml；location 能匹配锚点却没引用 → 违规 | `fish-stall` |
| `shot_size` | 枚举：远景/全景/中景/中近景/近景/特写 | `中近景` |
| `camera` | 枚举：固定/推/拉/摇/移/跟/环绕/手持 | `固定` |
| `lighting` | ≥6 字且必须含「光」和软硬词（柔/硬/直射/漫射/散射/透） | `右侧暖光，柔` |
| `palette` | ≥4 字且必须包含锚点 `palette_core` 全部色名 | `水泥灰、暖黄、泡沫箱白` |
| `scene_description` | ≥20 字散文（保留，给人读） | — |
| `props` / `visual_beats` | ≥1 件 / ≥2 条（保留） | — |

### 2.3 剧本【场景】行 v2（8 标签）

```
【场景】时间：清晨 ｜ 地点：老周鱼摊前的单宽通道 ｜ 景别：中近景 ｜ 机位：固定 ｜ 光线：右侧暖光，柔 ｜ 色调：水泥灰、暖黄低饱和 ｜ 物件：优鲜会员卡、电子秤、直播手机 ｜ 风格：写实纪录质感
≥30 字可拍描述段（来源：卡片 scene_description，可压缩不得新编）
```

- 8 标签缺一即 BLOCKER；`景别`/`机位` 走枚举校验；`光线` 含「光」；`色调` ≥4 字。
- 描述段保留 ≥30 字 + 模糊词黑名单（见 2.5）。

### 2.4 提示词导出器 `scripts/prompt.py`

```bash
python scripts/prompt.py <slug> --episode N [--scene K] [--mode image|video] [--write]
```

拼装顺序（按各家公式权重：靠前权重高）：

```
[主体] 人物形象四件套（persona/appearance/wardrobe/signature）+ 在场角色
[场景] 锚点 space + 本场 palette/lighting（锚点色在前）
[镜头] 景别、机位、9:16 竖屏构图提示
[动作] 本场 visual_beats（可观察动词，一镜一动作）
[风格] 风格标签 + 统一色调词
[约束] 保持项：人物五官/服装一致、不新增人物、画面无文字
[负向] 固定负向词表（模糊词、畸形、乱码文字、水印…）
```

- `--mode video` 额外拼声音三件套（对白原句/环境音/无 BGM 占位）与单镜头约束。
- 输出 stdout，`--write` 落 `episodes/eNN/prompts.md`。
- **红线**：`must_not_happen`、`must_not_know`、`hidden` 永不进入提示词（C4 面向人读，
  导出器结构性排除）。

### 2.5 QC 规则升级（C10 v2，全部 BLOCKER）

在 C10 原有（scene_description/props/visual_beats/剧本【场景】行）基础上新增：

| 规则号 | 检查 |
|--------|------|
| C10-card-ref | `scene_ref` 缺失或不在 scenes.yaml；location 匹配到锚点却未引用 |
| C10-card-shot | `shot_size` / `camera` 缺失或不在枚举词典 |
| C10-card-light | `lighting` 缺失、过短、不含「光」或不含软硬词 |
| C10-card-palette | `palette` 缺失、过短、不含锚点 `palette_core` 全部色名 |
| C10-fuzzy | scene_description / 剧本描述段命中模糊词黑名单 |
| C10-script-scene | 剧本【场景】行 8 标签校验（景别/机位枚举，光线含「光」，色调 ≥4 字） |

模糊词黑名单（初始）：`氛围感、高级感、唯美、仿佛、宛如、不禁、很有感觉、意境、
电影感、绝美、超美、巨美、如梦似幻`（与 W4 AI 味黑名单分开维护，
放 `config/fuzzy-words.json`，可扩展）。

### 2.6 分期与非目标

- 本期（本设计）：锚点库 + 卡片结构字段 + 剧本 8 标签 + prompt.py + C10 v2 + e01–e10 全量回填。
- W5.2b（后续）：分镜表 `shots.yaml` 把每场拆成镜头级提示词（一镜一动作）。
- 非目标：不生成图片/视频本身；不做风格迁移；不放开 Web 端编辑剧本。
