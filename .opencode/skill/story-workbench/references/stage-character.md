# S2 人物 Character Room

## LLM 角色：访谈者 + 心理侧写师

不写外貌清单，写**压力下的选择**。人物是通过"他想要/害怕/隐瞒什么"定义的，不是通过长相。

## 输入

- bible/premise.md（已批准的 logline 与引擎）
- bible/world.md、bible/voice.md
- decisions.jsonl（立意阶段的选择理由）

## 产出：3 份人物卡（主角、核心对手、关键配角）

每张卡按 data-model.md 的 character schema，核心是**五件套 + 声音**：

| 字段 | 要求 |
|------|------|
| want | 外在目标，具体可追 |
| fear | 内在恐惧，与 want 冲突 |
| secret | 绝不让别人知道的事 |
| lie | 对自己撒的谎 |
| wound | 哪一年被什么事改变 |
| voice_samples | 5 句只有他会说的话 |
| never_say | 至少 2 句他绝不会说的话 |
| arc | 一句话人物弧线 |
| persona | 个性：压力下的行为倾向，写可执行指令 |
| appearance | 外表：年龄感、体型、脸与手（可拍） |
| wardrobe | 穿着：标志性穿戴，可随 progressions 变化 |
| signature | 特征：习惯动作、身体标记、随身物 |

`persona / appearance / wardrobe / signature` 是**形象四件套**，QC 硬闸门（每项 ≥6 字），
剧本里角色本集首次出场的 `【人物】` 行必须与它一致。
剧本在场人物行若用简称或外号（"黄会长"vs"黄国平"），在 `aliases` 里列出来，否则对不上会记 W10。

## 生成方法（两步）

### 第一步：角色访谈

以访谈形式生成（不是档案形式），每个角色回答：

1. 你现在最想得到什么？为什么是现在？
2. 你最怕别人知道什么？
3. 你对自己撒的谎是什么？（他真心相信的假话）
4. 如果目标和道德二选一，你选哪个？举一个具体场景。
5. 你说话的节奏和口头禅是什么？

### 第二步：声音校准

- voice_samples 必须**遮住名字也能认出是谁**（三张卡的句式、长度、用词要拉开差距）
- 每个角色的 voice_rules 写成可执行指令（短句/爱用反问/从不道歉…），不写"温柔""强势"这类形容词
- 对照 voice.md 的文风禁令

## 硬约束

- want 与 fear 必须构成内在冲突（他追的东西恰好通向他怕的东西）
- 主角与对手的 want 必须**零和对立**（同一资源，你得我失）
- 不许出现"圣母"：主角必须有可指摘的道德瑕疵（对应 lie/wound）
- 每张卡必须能回答"他最怕别人知道什么"

## 用户决策点

展示 3 份访谈式人物卡，用户可：确认 / 改字段 / 要求重新访谈某角色 / 补充第 4 个人物。

确认后一人一卡写入 `bible/characters/<id>.yaml`。

## 进度

- characters 目录满 3 份且过校验 → 请批准 → S3
- decisions.jsonl 记录每次 select/revise
- `validate.py <slug> --stage characters`
